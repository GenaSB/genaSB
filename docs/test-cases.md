# Тест-кейсы: E2E сценарий покупки товара

**Проект:** E2E UI тесты для интернет-магазина  
**Ссылка:** https://github.com/GenaSB/genaSB

---

## TC-001: Подготовка страницы и авторизация

**Предусловие:** Открыт сайт интернет-магазина.

### Шаг 1: Подготовка страницы

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1.1 | Закрыть всплывающее окно выбора города (нажать крестик) | Окно выбора города скрыто |
| 1.2 | Отказаться от cookie (нажать «Отклонить») | Cookie-баннер скрыт |

### Шаг 2: Авторизация

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 2.1 | Нажать кнопку «Войти» | Открылась форма авторизации |
| 2.2 | Ввести логин | Логин введён в поле |
| 2.3 | Ввести пароль | Пароль введён в поле |
| 2.4 | Нажать кнопку «Войти» | Пользователь авторизован, отображается имя |

**Статус:** ✅ Автоматизирован

## TC-002: Фильтрация и выбор товара

**Предусловие:** Пользователь авторизован.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Перейти в каталог | Открылся каталог товаров |
| 2 | Применить фильтр (категория «Ноутбуки») | Отображаются товары по фильтру |
| 3 | Выбрать товар | Открылась карточка товара |
| 4 | Проверить цену | Цена соответствует каталогу |
| 5 | Проверить наименование | Наименование соответствует каталогу |

**Статус:** ✅ Автоматизирован
