# Тест-кейсы: E2E сценарий покупки ноутбука

**Проект:** E2E UI тесты для интернет-магазина  
**Ссылка:** https://github.com/GenaSB/genaSB

---

## TC-001: Подготовка страницы и авторизация

**Предусловие:** Открыт сайт интернет-магазина.

### Шаг 1: Подготовка страницы

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1.1 | Нажать на крестик в окне выбора города | Окно выбора города скрыто |
| 1.2 | Нажать кнопку «Отклонить» в cookie-баннере | Cookie-баннер скрыт |

### Шаг 2: Авторизация

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 2.1 | Нажать на кнопку «Войти» в шапке сайта | Открылась форма авторизации |
| 2.2 | Ввести в поле «Логин» тестовые учётные данные | Логин введён |
| 2.3 | Ввести в поле «Пароль» тестовые учётные данные | Пароль введён |
| 2.4 | Нажать на кнопку «Войти» | Пользователь авторизован |
| 2.5 | Проверить, что в шапке отображается имя `User2` | Имя = **User2** |

**Статус:** ✅ Автоматизирован

## TC-002: Переход в каталог ноутбуков

| Шаг | Действие | Ожидаемый результат |

| 3 | Проверить заголовок раздела | Заголовок = **Ноутбуки** |

**Статус:** ✅ Автоматизирован

## TC-003: Фильтрация товаров

**Предусловие:** Открыт раздел «Ноутбуки».

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Установить чекбокс «Объём SSD» → «512 ГБ» | Чекбокс отмечен |
| 2 | Установить чекбокс «Тип привода» → «НЕТ» | Чекбокс отмечен |
| 3 | Установить чекбокс «Тип графического контроллера» → «Интегрированный» | Чекбокс отмечен |
| 4 | Установить чекбокс «Вес» → «От 1,5 до 2 кг» | Чекбокс отмечен |
| 5 | Нажать на кнопку «Показать всё» | Отображаются отфильтрованные товары |
| 6 | Проверить заголовок раздела | Заголовок = **Ноутбуки** |

**Статус:** ✅ Автоматизирован

## TC-004: Выбор ноутбука и проверка данных

**Предусловие:** Товары отфильтрованы.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Сохранить цену первого товара из списка | Цена сохранена |
| 2 | Сохранить название первого товара из списка | Название сохранено |
| 3 | Нажать на название первого товара | Открылась карточка товара |
| 4 | Проверить, что раздел «Характеристики» отображается | Раздел отображается |
| 5 | Сохранить название на странице товара | Название сохранено |
| 6 | Сверить название (список ↔ карточка) | **Совпадает** |
| 7 | Сохранить цену на странице товара | Цена сохранена |
| 8 | Сверить цену (список ↔ карточка) | **Совпадает** |

**Статус:** ✅ Автоматизирован

## TC-007: Оформление заказа

**Предусловие:** Открыта страница оформления.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Установить радиокнопку «Физическое лицо» | Получатель выбран |
| 2 | Сверить название товара | **Совпадает** |
| 3 | Сверить цену товара | **Совпадает** |
| 4 | Установить радиокнопку «Самовывоз» | Способ получения выбран |
| 5 | Установить радиокнопку «Онлайн» | Способ оплаты выбран |
| 6 | Ввести в поле «Комментарий» значение `I want to buy this product as soon as possible.` | Комментарий введён |
| 7 | Установить чекбокс «Согласие на обработку персональных данных» | Согласие подтверждено |

**Статус:** ✅ Автоматизирован
